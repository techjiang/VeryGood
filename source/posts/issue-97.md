粉色之所以常被误解，是因为多数人见过的是「糖果粉」。真正耐看的粉色，是玫瑰灰、藕粉、豆沙粉——带着一点灰度和温度的颜色。

## 粉色配色的三个原则

### 1. 降低饱和度

> 粉色的高级感来自灰度，而不是亮度。加一点灰，甜腻感立刻消失。

对比下面两组颜色，左边是考虑过的「玫瑰灰」，右边是常见的「亮粉」：

| 用途 | 推荐（灰调粉） | 避雷（艳粉） |
| --- | --- | --- |
| 正文 | `#6E5661` | `#FF66CC` |
| 背景 | `#FBF8F9` | `#FFE4F2` |
| 强调 | `#C0778E` | `#FF2E93` |

### 2. 控制面积

大面积用浅色背景，小面积用深色点缀。整套页面里，高饱和粉色的占比建议控制在 10% 以内。

### 3. 搭配中性色

粉 + 白 + 少量深灰，是最不容易出错的组合。这与 VeryGood 主题默认配色的逻辑一致：**背景近乎奶白、文字深玫瑰灰、强调色留到按钮和链接**。

```css
:root {
  --rose-500: #C0778E; /* 强调 */
  --bg: #FBF8F9;       /* 大面积背景 */
  --ink: #3A2A31;      /* 正文 */
}
```

## 生活中的应用

- 穿搭：灰调粉色的针织开衫优于荧光粉卫衣；
- 家居：墙面用米白，抱枕和挂画用藕粉；
- 摄影：日落前后一小时的光线自带玫瑰色调。

## 结语

美学的本质是克制。粉色如此，设计如此，写博客也是如此——**把内容留在最干净的位置**，这正是 VeryGood 想做的事。
