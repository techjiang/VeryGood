# VeryGood 使用文档

> 面向博主：从零开始部署、写作、配置与日常维护。适合**不打算改代码**的用户。

- 版本：v1.1.6（2026-08，公告升级为弹窗样式）
- 另见：[开发文档](./开发文档.md)（面向想改主题 / 写插件 / 了解原理的用户）

---

## 1. 什么是 VeryGood

VeryGood 是一个跑在 **GitHub Pages** 上的开源博客主题：

- **写文章**：不用碰代码、不用拉仓库——直接在 GitHub 的 **Issue 里写 Markdown**，打一个 `Article` 标签，文章就自动上线。
- **改样子**：不换主题不用求人——一个 `config.yml` 就能管住站名、公告、侧栏、右栏、友链、评论、SEO。
- **个性化**：侧栏内容、分类/标签描述、友链头像、公告、朋友圈动态……都能自己加。
- **免费且稳定**：Pages + Actions 全部由 GitHub 免费提供；构建是一次性的本地 Python 脚本，不依赖任何第三方服务。

## 2. 部署步骤（第一次）

### 2.1 创建自己的仓库

1. 打开 VeryGood 的 GitHub 仓库，点 **Use this template → Create a new repository**；
2. 仓库名建议填 **`你的用户名.github.io`**（这样站点地址就是这个域名）；
3. 创建完成后，这个仓库就是你的博客仓库。

> 提示：仓库创建后里面自带的 5 篇示例文章（`source/posts/issue-*.md`）可以先删掉，避免和你的内容混在一起。

### 2.2 修改配置

网页上直接改 `config.yml`（点铅笔图标编辑）最省事。**至少改这三处**：

```yaml
site:
  title: 我的博客          # 站点名（显示在侧栏与标题栏）
  url: https://你的用户名.github.io   # 你的真实站点地址，不要带末尾斜杠
author:
  name: 你的名字          # 侧栏头像旁显示的名字
```

顺带可以改：`site.subtitle`（副标题）、`author.avatar`（头像图 URL）、`author.bio`（一句话介绍）、`links`（你的友链列表）。

改完点 **Commit changes**，会自动触发一次构建。

### 2.3 开启 GitHub Pages

仓库 **Settings → Pages**：

- **Source** 选择 **GitHub Actions**（不要选 Branch）；
- 保存后等第一次 Actions 跑完（Actions 页能看到 `Deploy VeryGood Blog` 工作流）；
- 打开 `https://你的用户名.github.io` 就能看到你的博客了。

> 若提示 DNS/证书未生效，通常等 1~2 分钟即可。

## 3. 写文章（Issue 即文章）

### 3.1 发布一篇

1. 仓库 **Issues → New issue**；
2. 正文写 Markdown（支持标题、列表、代码块、表格、图片、脚注等完整语法）；
3. 右侧 **Labels** 勾选 **`Article`**（必须）；
4. 点 **Create**，等 Actions 构建完成即可看到新文章。

### 3.2 标签即状态机

| 标签 | 效果 |
| --- | --- |
| `Article` | 发布文章（标签名可在 `config.yml issues.publish_label` 改） |
| `Draft` | 草稿，线上不可见；本地 `python -m verygood build --drafts` 可预览 |
| `Page` | 独立页面（比如「关于我」），不进入文章流 |
| `Moment` | 朋友圈动态，展示在 `/board/` 时间线（详见 4.7） |
| `分类:xxx` | 归入分类 xxx（兼容 `category:xxx` / `Category:xxx`） |
| 任意标签 | 自动成为文章的 tag，进标签页/标签云 |
| 无这些标签 | 不发布、不同步（普通 Issue 仅用于讨论） |

### 3.3 状态流转

- **关闭 Issue** → 文章从站点下线（同名 `source/posts/issue-N.md` 被自动删除）；
- **重新打开** → 文章恢复上线；
- **编辑正文** → 内容自动更新；
- **改标签** → 分类/标签自动变化。

### 3.4 在 Issue 里插入图片/视频

- **图片**：直接把图片拖进 Issue 文本框，GitHub 会上传到 `user-images.githubusercontent.com` 并插入 Markdown。发布后正文里点击图片可看**灯箱大图**（支持键盘左右切换同一篇文章的图片、ESC 关闭）。
- **视频**（YouTube / B 站），写短代码：

```markdown
{{< youtube dQw4w9WgXcQ >}}
{{< bilibili BV1xx411c7mD >}}
```

## 4. 配置详解（config.yml 全字段）

### 4.1 站点基础

```yaml
site:
  title: 我的博客
  subtitle: 记录日常与代码
  description: 一句话给搜索引擎看的站点描述
  keywords: [博客, 生活]        # 可省略
  url: https://you.github.io    # 必填
  basePath: ""                  # 部署在 https://user.github.io/repo/ 时填 repo
  language: zh-CN
  timezone: Asia/Shanghai
  footer_text: "© 2026 我"       # 页脚自定义文字（默认隐藏版权行，可留空）
```

> 注意：`basePath` 只在子路径部署时需要，`你的用户名.github.io` 这种根域名部署一律留空。

### 4.2 公告弹窗（v1.1.6）

进入页面后自动弹出的居中小弹窗，可带标题和链接按钮；访客关闭后本浏览器不再弹（localStorage 记忆）。

```yaml
site:
  announcement:
    enabled: true          # 关掉就把这里改 false
    title: "欢迎来到 VeryGood"     # 弹窗标题，留空 "" 则只显示文案
    text: "🎉 新文章已发布"        # 支持少量 HTML，比如 <a href="...">
    link: "/board/"        # 跳转地址，留空 "" 则不显示按钮
    btn_text: "去看看"      # 按钮文案，留空默认「了解更多」
    type: info             # 三种风格：info（粉）/ tip（青）/ warn（橙）
```

弹窗出现于页面加载约 1 秒后；点右上 ×、ESC 或点击弹窗外区域均可关闭。

### 4.3 左侧栏（v1.1）

左侧栏自上而下固定为：**站点信息（头像+站名+bio）→ 最近更新（可折叠）→ 导航 → 自定义模块**。

```yaml
site:
  sidebar:
    recent_count: 5        # 最近更新展示条数
    collapse: false        # true 时最近更新默认折叠，访客可点开
    custom:                # 自定义模块：想放什么放什么
      - title: 我的项目
        icon: "⚡"
        html: "<p><a href='https://github.com/me/proj'>Project A</a></p><p>这里写任意 HTML</p>"
      - title: 打赏
        icon: "🎁"
        html: "<p>…</p>"
```

- 导航项用 `site.nav` 追加（如友链、关于）；动态入口已内置在导航与页脚。
- 移动端（<861px）左侧栏自动收入汉堡菜单。

### 4.4 右侧栏（v1.1）

宽屏（≥1366px）时显示在正文右侧（330px 宽），放置：**文章目录**（文章页）、**近期文章**、**标签云**、**分类**、**友链缩略**。中等屏（861–1365px）自动隐藏并改为折叠目录，保证正文宽敞。

```yaml
site:
  rightbar:
    enabled: true
    show_toc: true         # 文章目录放右栏（正文不再被目录挤压）
    show_recent: true
    recent_count: 5
    show_tags: true
    tags_max: 24
    show_categories: true
    show_links: true
    links_max: 8
```

### 4.5 作者信息

```yaml
author:
  name: 你的名字
  email: you@example.com
  avatar: "https://example.com/avatar.png"   # 留空则不显示头像
  bio: 一句介绍
  social:
    github: yourname
    twitter: ""
    weibo: ""
    rss: ""                # 留空自动指向 /rss.xml
```

### 4.6 分类 / 标签的描述与置顶（v1.1）

给分类/标签写介绍、置顶，会在归档页（分类云）与标签页展示：

```yaml
taxonomies:
  categories:
    技术:
      desc: 技术相关文章都会放这里
      pin: true            # 置顶：排在分类云前面
    生活:
      desc: 记录生活的碎片
  tags:
    verygood:
      desc: 关于 VeryGood 主题本身的文章
      pin: true
```

> 分类/标签的名字不需要预先声明——**文章里用了就会自动出现**。这里的配置只是为了「加描述」和「排序置顶」。

### 4.7 朋友圈动态（v1.1.2）

位于 `/board/`：**站长/站点管理者**的朋友圈式动态时间线。动态内容不是访客留言，而是由站长通过 **GitHub Issue + Actions 推送**的碎碎念、站点公告、更新日志等——像发朋友圈，关闭对应 Issue 即下线。

发布一条动态：

1. 在仓库新建 Issue，正文写下动态内容（Markdown，支持图片、视频）；
2. 给 Issue 打上 **`Moment`** 标签；
3. Actions 自动同步为 `source/moments/` 下的文件并部署，页面即时更新。

```yaml
board:
  enabled: true    # false 则不出生成 /board/ 页面
  title: 朋友圈动态
  desc: 页面顶部的介绍文字
  per_page: 30     # 时间线最多展示条数
  repo: ""         # 填 "你的用户名/仓库名"：动态卡片带「Issue #编号」跳转到对应 GitHub Issue；留空不显示
  giscus: false    # 设为 true 时在动态页下方再挂一套 giscus 评论（需要先配置 comments.giscus）
```

> 说明：`Moment` 是 `issues.moment_label` 的默认值，可改名。`Moment` 与 `Article` / `Draft` / `Page` 互斥：打上多个时按 Page > Moment > Draft > Article 取其一。手写 markdown 放到 `source/moments/` 也可以（需要带 front matter，见 `scripts/sync_issues.py` 生成的示例）。

### 4.8 评论（文章页）

```yaml
comments:
  provider: giscus      # none 关闭 / giscus / utterances
  giscus:
    repo: "你的用户名/评论仓库名"
    repo_id: "R_xxx"          # 从 giscus.app 获取
    category: "Announcements"
    category_id: "DIC_xxx"
    mapping: pathname
    lang: zh-CN
```

配置方法：打开 [giscus.app](https://giscus.app)，选评论仓库并生成配置，把 `repo / repo_id / category / category_id` 四项抄进来即可。utterances 只需填 `repo`。

### 4.9 友链（支持图片头像 v1.1）

`/links/` 页大卡片 + 右栏缩略共用这份数据：

```yaml
links:
  - name: GitHub
    url: https://github.com
    desc: 给友链写一句话介绍
    avatar: "https://github.com/github.png"   # 头像图 URL；留空自动显示首字母彩球
  - name: 另一博客
    url: https://example.com
    desc: 纸上得来终觉浅
    # avatar 不填 = 彩球头像（按名字首字符自动配色）
```

### 4.10 文章与 SEO

```yaml
posts:
  per_page: 8            # 首页每页文章数
  excerpt_length: 150    # 摘要字数
  toc: true              # 生成文章目录（宽屏在右栏，窄屏折叠在正文头部）
  toc_depth: 2-3         # 目录抓取 h2~h3
  related: 3             # 文章尾部相关推荐条数
  date_format: "%Y-%m-%d"
  cover_default: ""      # 文章没写封面时的兜底封面

seo:
  image: /assets/og-default.png   # 分享到微信/推特时显示的默认图
  twitter_handle: "@xxx"
  google_site_verification: ""    # Google Search Console 验证 token
  baidu_site_verification: ""     # 百度站长验证 token
  baidu_push: false               # 百度主动推送（构建产物带推送脚本）
  sitemap: true                   # sitemap.xml（含首页/文章/页面/标签/分类/归档/动态 + 图片）
  rss: true
  robots: true                    # robots.txt + humans.txt
  noindex_page_2plus: true        # 分页第 2 页起对搜索引擎 noindex（防重复内容）
```

### 4.11 插件

```yaml
plugins: []    # 用户插件显式声明（相对仓库根的目录路径）
```

但**更简单的方式**：直接在仓库根建 `plugins/` 目录，丢一个 `my-plugin/plugin.py` 进去就自动加载，无需改 config。见 [开发文档](./开发文档.md) 的插件章节。

## 5. 常见任务清单

| 想做什么 | 怎么做 |
| --- | --- |
| 发一篇文章 | 新建 Issue + 打 `Article` 标签 |
| 撤下一篇文章 | 关闭对应 Issue |
| 改站名/头像/介绍 | 改 `config.yml` 相应字段 |
| 加一个友链 | `links` 列表加一行 |
| 加导航入口 | `site.nav` 追加一行 |
| 加侧栏小模块 | `site.sidebar.custom` 加一条 HTML |
| 挂评论区 | 按 4.8 配置 giscus / utterances |
| 发一条朋友圈动态 | 新建 Issue + 打 `Moment` 标签（展示在 /board/） |
| 显示公告 | `site.announcement.enabled: true` 并写 text（弹窗样式） |
| 换主色调 | `themes/verygood/static/css/main.css` 顶部 `:root` 变量 |
| 本地预览 | `python -m verygood serve` |

## 6. 本地预览（可选）

想在自己电脑上预览效果：

```bash
cd VeryGood
pip install -r requirements.txt
python -m verygood build          # 构建到 dist/
python -m verygood serve          # 打开 http://localhost:8000（默认为 8000，可用 --port 改）
```

`serve` 会自动监听 config/主题/文章变化并增量重建，适合改主题调样式。

> 依赖：Python 3.10+。Windows / macOS / Linux 均可。

## 7. 常见问题

**Q：建好仓库后站点打不开？**
先确认 Settings → Pages 的 Source 选了 **GitHub Actions**；再到 Actions 页看工作流是否成功；成功但 404，检查 `site.url` 是否写对、是否多了末尾斜杠。

**Q：发了 Issue 但站点没更新？**
确认标签是 **`Article`** 且拼写一致；确认工作流没排队/失败；Issue 正文为空也可能被跳过。

**Q：草稿怎么看？**
本地 `python -m verygood build --drafts` 后 `serve` 预览。线上不会出现。

**Q：朋友圈动态想加图片/视频？**
直接在 Issue 正文用 Markdown 写 `![alt](图片URL)` 或粘贴视频，Actions 同步后自动出现在时间线卡片里，点图片可放大（灯箱）。

**Q：公告弹窗怎么关？**
`site.announcement.enabled: false`；对单个访客，点弹窗右上 × / ESC / 弹窗外区域，即永久（本浏览器）关闭。

**Q：想让别人复制我的主题时也连同自定义一起？**
VeryGood 鼓励 fork 后魔改：主题在 `themes/`、插件在 `plugins/`、配置在 `config.yml`，改完整体推上去即生效。
