# VeryGood 插件使用文档

> 面向博主：了解内置插件的功能、配置与启停方式，无需写任何代码。
> 版本：v1.5.1（2026-08，插件系统 v1.5.0 起稳定）
> 另见：[使用文档](./使用文档.md)（部署、写作与日常配置）、[开发文档](./开发文档.md)（主题原理与源码结构）、[插件开发文档](./插件开发文档.md)（面向写插件的开发者）

---

## 1. 什么是插件

插件是给博客"加功能"的扩展模块。VeryGood 内置 5 个插件，开箱即用，覆盖站点数据展示、时钟微语、视频嵌入、阅读时长、随机文章等常见需求。

插件的特点：

- **开箱即用**：内置插件构建时自动加载，多数无需任何配置。
- **可插拔**：不需要的插件可以一键禁用，不会影响其他功能。
- **可扩展**：除了内置插件，还可以把第三方插件放到 `plugins/` 目录下自动加载。

> 插件加载失败不会中断整站构建——出错的插件会被跳过，其余功能照常运行。本地预览（`serve`）时请留意控制台日志。

## 2. 内置插件一览

| 插件名 | 功能 | 是否需要配置 |
| --- | --- | --- |
| `site-stats` | 左侧栏站点数据卡片（文章/字数/浏览/访客） | 否，默认开启 |
| `whisper` | 右栏时钟卡片 + 打字机微语轮播 | 可选，自定义微语内容 |
| `shortcodes` | 文章正文嵌入 YouTube / B 站视频 | 否，自动启用 |
| `reading_time` | 文章页标题下方显示预计阅读时长 | 否，自动启用 |
| `random_post` | 访问 `/random/` 随机跳转一篇文章 | 否，自动启用 |

## 3. 启用与禁用插件

### 3.1 内置插件

内置插件在构建时自动加载，无需手动声明。如果某个内置插件不需要，可以通过 `config.yml` 的 `plugins_disabled` 列表关闭：

```yaml
plugins_disabled:
  - "site-stats"      # 关闭左侧栏站点数据卡片
  - "whisper"         # 关闭右栏时钟与微语
  - "shortcodes"      # 关闭视频嵌入短代码
  - "reading_time"    # 关闭阅读时长显示
  - "random_post"     # 关闭随机文章页面
```

只需列出要禁用的插件名，未列出的内置插件照常运行。

### 3.2 第三方 / 用户自定义插件

第三方插件放在仓库根目录的 `plugins/` 文件夹下，构建时自动发现并加载：

```
plugins/
└── my-plugin/
    └── plugin.py       # 插件入口文件，必须存在
```

也可以在 `config.yml` 中显式声明（适合插件不在 `plugins/` 目录下的情况）：

```yaml
plugins:
  - "plugins/my-plugin"
```

### 3.3 查看当前插件清单

在仓库根目录运行：

```bash
python -m verygood plugins
```

会列出所有内置插件、自动发现的用户插件和已禁用的插件，包括名称、描述、版本等信息。此命令只读取插件元信息，不执行插件代码，可以安全运行。

## 4. 内置插件详解

### 4.1 site-stats — 站点数据卡片

**位置**：左侧栏，站点信息下方。

**展示内容**：文章总数、全站字数、浏览量、访客数，以四宫格卡片形式呈现。

- 文章数和总字数在构建时静态生成，无需 JavaScript 即可显示。
- 浏览量和访客数通过不蒜子（busuanzi）统计服务实时填充；当不蒜子不可用时，自动降级到 ibruce，最终兜底使用浏览器 localStorage 本地统计。

**配置**：

在 `config.yml` 的 `site.sidebar` 节中控制开关：

```yaml
site:
  sidebar:
    site_data: true       # true 开启（默认），false 关闭
```

无需其他配置，插件自动统计并展示。

> 也可以通过 `plugins_disabled: ["site-stats"]` 完全禁用此插件。

### 4.2 whisper — 时钟与微语

**位置**：右侧栏，近期文章列表之后。

**展示内容**：

- **时间卡片**：显示当前时间（本地时间，秒级刷新）和日期。
- **微语卡片**：以打字机效果逐字显示短句，自动轮播，鼠标悬停可暂停。

**配置**：

在 `config.yml` 的 `site.rightbar` 节中控制：

```yaml
site:
  rightbar:
    enabled: true           # 右栏总开关，必须为 true 时钟与微语才会显示
    show_clock: true        # 是否显示时间卡片（默认 true）
    show_micro: true        # 是否显示微语卡片（默认 true）
    micro_notes:            # 自定义微语内容，每行一条
      - "保持热爱，奔赴山海"
      - "代码改变世界"
      - "记录每一个灵感瞬间"
      - "好代码如好诗：简练、清晰、有余韵"
```

- `micro_notes` 留空（`[]`）或不填时，使用插件内置的默认文案。
- 建议微语条数不超过 12 条，轮播体验最佳。

### 4.3 shortcodes — 视频嵌入

**位置**：文章正文中使用。

**功能**：在 Markdown 文章中嵌入 YouTube 或 Bilibili 视频，自动生成响应式播放器。

**用法**：

在文章 Markdown 中直接写短代码：

```markdown
嵌入 YouTube 视频（VIDEO_ID 是视频地址中 watch?v= 后面的部分）：

{{< youtube dQw4w9WgXcQ >}}

嵌入 B 站视频（BV 开头的完整 BV 号）：

{{< bilibili BV1xx411c7mD >}}
```

- YouTube 使用 `youtube-nocookie` 隐私增强域名嵌入。
- B 站默认高清画质、关闭弹幕。
- 短代码在代码块（` ``` `）内不会生效，仅处理正文中的短代码。

**配置**：无需配置，自动启用。

### 4.4 reading_time — 阅读时长

**位置**：文章页标题下方。

**功能**：根据文章正文字数自动估算阅读时长，显示为"约 N 分钟"。

- 统计范围：文章正文 HTML 中的可见文字。
- 估算速率：约 350 字/分钟，取整后至少 1 分钟。

**配置**：无需配置，自动注入到文章页。

> 构建引擎内置了阅读时长计算，此插件在文章解析阶段追加统计字段。两者协作确保每篇文章都有阅读时长显示。

### 4.5 random_post — 随机文章

**位置**：访问 `/random/` URL。

**功能**：生成一个随机跳转页面。访客访问 `你的域名/random/` 时，会自动随机跳转到站内任意一篇文章。

- 跳转逻辑在前端执行，每次访问结果不同。
- 如果站点没有文章或未启用 JavaScript，会回退到首页。
- 页面设置了 `noindex,nofollow`，不会被搜索引擎收录。

**配置**：无需配置，自动生成 `/random/index.html`。

**使用方式**：

在导航栏、友链或文章中添加一个指向 `/random/` 的链接即可：

```yaml
# config.yml 中添加导航项示例
site:
  nav:
    - label: "手气不错"
      url: "/random/"
```

## 5. 安装第三方插件

VeryGood 支持安装第三方插件来扩展功能。安装步骤：

1. **获取插件**：从插件作者处获取插件目录（通常包含 `plugin.py` 文件）。
2. **放入目录**：将插件目录放到仓库根的 `plugins/` 文件夹下：

   ```
   plugins/
   └── example-plugin/
       ├── plugin.py          # 插件入口，必须存在
       └── static/            # 可选：插件自带的 CSS/JS 资源
   ```

3. **构建生效**：下次构建时自动加载，无需修改 `config.yml`。

仓库中已自带两个示例插件，可以参考或直接使用：

- **`plugins/footer-note/`**：在页脚显示自定义留言文字。配置方式：
  ```yaml
  site:
    footer:
      plugin_note: "用 VeryGood 搭建"
  ```
  此插件同时注册了 `{{< bili 用户ID >}}` 短代码，可在文章中快速插入 B 站个人主页链接。

- **`plugins/post-stats/`**：为文章增加中英文混合字数统计，并注册 `| reading_time` 和 `| wc` 两个 Jinja 过滤器供模板使用。放在 `plugins/` 下即自动生效，无需配置。

> 不需要的第三方插件，直接从 `plugins/` 目录删除即可卸载，不会留下任何残骸。也可以通过 `plugins_disabled` 列表禁用而不删除文件。

## 6. 常见问题

**Q：禁用了某个插件后页面布局会错乱吗？**
不会。插件注入的内容是独立的模块，禁用后对应区域留空或折叠，不影响其他布局。

**Q：第三方插件会覆盖内置插件吗？**
不会。内置插件和用户插件独立运行，互不干扰。如果两者注册了同名短代码，用户插件优先。

**Q：如何确认插件是否正常加载？**
运行 `python -m verygood plugins` 查看插件清单，或使用 `python -m verygood serve` 本地预览时留意控制台日志——加载失败会有明确提示。

**Q：插件配置改了不生效？**
确保修改的是仓库根目录的 `config.yml`，然后重新构建或刷新本地预览。`serve` 模式会监听 `plugins/` 目录变化自动重建，但 `config.yml` 修改后可能需要手动重启。
