> 面向想要改进、扩展、调试 VeryGood 主题的开发者。当前版本 **v1.5.1**。
> 仓库：<https://github.com/techjiang/VeryGood> ｜ 线上：<https://techjiang.github.io/VeryGood/>

## 1. 本地开发环境

### 1.1 前置依赖

Python 3.8+，依赖包：Jinja2 / PyYAML / Markdown / Pygments / pypinyin。

```bash
pip install -r requirements.txt
# 或手动安装：pip install jinja2 pyyaml markdown pygments pypinyin
```

### 1.2 本地构建与预览

```bash
python -m verygood build           # 构建静态站到 dist/
python -m verygood serve            # 本地预览（默认 :8000，支持热重建）
python -m verygood build --drafts   # 含草稿构建
python -m verygood serve --port 3000
python -m verygood version
python -m verygood plugins          # 查看插件清单
```

`serve` 模式启动后，文件监听器（`verygood/cli.py:81` `watched()`）持续监控 `source/`、模板、静态资源、`config.yml` 以及 `plugins/` 和 `scripts/` 下的 `.py` 文件。任一文件变动即自动重建，浏览器刷新即见变更。

### 1.3 目录结构

```
VeryGood/
├── config.yml                # 站点配置
├── verygood/                 # 主题引擎
│   ├── __init__.py           # 版本信息（__version__ = "1.5.1"）
│   ├── cli.py                # 命令行（build / serve / version / plugins）
│   ├── config.py             # 配置加载与默认值
│   ├── content.py            # Front Matter 解析 / 拼音 slug / pin 字段
│   ├── mdrender.py           # Markdown 渲染 / TOC / 懒加载 / 短代码 / 语言标签
│   ├── seo.py                # sitemap / rss / robots / humans
│   ├── builder.py            # 核心编排：模型/分页/渲染/输出/署名校验
│   └── plugins/              # 内置插件（site-stats / whisper / shortcodes 等）
├── themes/verygood/
│   ├── templates/            # Jinja2 模板（base / index / post / partials 等）
│   └── static/               # CSS / JS（main.css / main.js / search.js）
├── source/                   # 内容源（posts / pages / moments）
├── plugins/                  # 用户插件目录（自动发现）
├── scripts/                  # GitHub Actions 同步脚本
└── dist/                     # 构建输出（.gitignore，Actions 云端重建）
```

## 2. 主题架构

### 2.1 构建流程

```
config.yml + source/ → verygood 构建器 → dist/
```

完整流程（`verygood/builder.py:223` `build()`）：

1. **加载配置**：`config.py:125` `load_config()` 将 `config.yml` 与 `DEFAULTS`（`config.py:11`）深合并，经 `normalize()`（`config.py:137`）规整
2. **加载插件**：`plugins/__init__.py:148` `load_plugins()` 发现并执行内置/用户插件
3. **Markdown 管线**：`mdrender.py:80` `build_markdown()` 配置扩展（fenced_code / codehilite / toc / tables 等）
4. **加载内容**：`content.py` 分别从 `source/posts/`、`source/pages/`、`source/moments/` 读取
5. **站点模型**：`builder.py:79` `build_site_model()` 聚合标签/分类/归档/右栏数据，处理置顶排序
6. **渲染模板**：Jinja2 环境初始化（`builder.py:152` `_env()`），逐页渲染输出
7. **SEO 文件**：sitemap.xml / rss.xml / robots.txt / humans.txt
8. **静态资源**：主题 static/ 和 source/assets/ 复制到 dist/
9. **CSS 压缩**：`builder.py:31` `minify_css()` 压缩主题自带 CSS
10. **署名校验**：`builder.py:423` 逐页校验页脚署名完整性
11. **插件收尾**：触发 `finalize` 钩子

### 2.2 核心模块

#### `verygood/config.py` — 配置加载

`DEFAULTS`（`config.py:11`）定义所有配置项默认值。`load_config()`（`config.py:125`）读取 `config.yml` 深合并后调 `normalize()`（`config.py:137`）规整 URL、basePath、公告、侧栏等字段。`url_for()`（`config.py:272`）和 `abs_url()`（`config.py:283`）处理站内相对/绝对 URL，自动拼接 basePath。

#### `verygood/content.py` — 内容解析

`split_front_matter()`（`content.py:17`）用正则分离 YAML Front Matter 与正文。`parse_post_file()`（`content.py:75`）解析单篇文章，提取 title/date/tags/category/cover/pin 等字段。`_pinyin_slug()`（`content.py:182`）为 v1.5.0 新增——中文标题转拼音 slug（字间连字符，英文/数字保留原样）。`pin` 字段（`content.py:117`）实现 Front Matter `pin: true` 的文章置顶。slug 优先级（`content.py:232`）：Front Matter `slug` > 拼音转换 > stem。

#### `verygood/mdrender.py` — Markdown 渲染

`build_markdown()`（`mdrender.py:80`）配置 Python-Markdown 扩展。`render()`（`mdrender.py:101`）渲染管线：Markdown 转 HTML → 代码块语言标签装饰（`mdrender.py:62` `_decorate_code_langs()`）→ 短代码展开（`mdrender.py:151` `process_shortcodes()`）→ 图片懒加载（`mdrender.py:135` `_lazy_images()`）。`toc_html()`（`mdrender.py:117`）把 toc_tokens 渲染为嵌套 `<ul>` 目录树。

#### `verygood/seo.py` — SEO 输出

`sitemap_xml()`（`seo.py:8`，含 image sitemap）、`rss_xml()`（`seo.py:50`，RSS 2.0 + UTC 日期）、`robots_txt()`（`seo.py:86`）、`humans_txt()`（`seo.py:96`）。

#### `verygood/builder.py` — 核心编排

`build_site_model()`（`builder.py:79`）聚合标签/分类/归档，构建右栏数据，处理置顶排序。`_env()`（`builder.py:152`）初始化 Jinja2 环境，注入全局变量（`url_for` / `abs_url` / `tax_path` / 署名指纹）和过滤器。`paginate()`（`builder.py:40`）列表分页。署名校验（`builder.py:423`）详见第 4 节。

#### `verygood/plugins/` — 内置插件

| 插件 | 位置 | 注入点 | 功能 |
|------|------|--------|------|
| site-stats | `plugins/site-stats/plugin.py` | `sidebar_data` | 左栏站点数据（文章数/标签数/访问统计三级降级） |
| whisper | `plugins/whisper/plugin.py` | `rightbar` | 右栏微语卡片（打字机效果） |
| shortcodes | `plugins/shortcodes.py` | 短代码 | `{{< youtube >}}` / `{{< bilibili >}}` |
| reading_time | `plugins/reading_time.py` | `post_parsed` 钩子 | 计算阅读时间 |
| random_post | `plugins/random_post.py` | 短代码 | `{{< random_post >}}` 随机跳转 |

插件系统注入位置（`plugins/__init__.py:30`）：`head` / `header_extra` / `footer_extra` / `body_end` / `sidebar_data` / `content_top` / `content_bottom` / `rightbar`。

## 3. 主题模板结构

### 3.1 基础模板 `base.html`

`themes/verygood/templates/base.html` 是所有页面的基础模板，关键区块：

- **`<head>` SEO**（`base.html:4-72`）：meta 标签、Open Graph、Twitter Card、JSON-LD 结构化数据、RSS、CSS 引入
- **公告弹窗**（`base.html:76-95`）：条件渲染，ESC/遮罩关闭，localStorage 记忆已读
- **左侧栏**（`base.html:98-186`）：头像 → 工具栏 → 自定义模块 → 最近更新 → 站点数据 → 幻灯片 → 导航
- **主内容区**（`base.html:188-192`）：`{% block content %}` 占位
- **右栏**（`base.html:194-242`）：近期文章 → 插件注入 → 标签云 → 分类 → 友链
- **页脚**（`base.html:243-269`）：探索/关于两栏 + 署名锁定行
- **浮动控件**（`base.html:271-294`）：进度条、回到顶部、媒体灯箱
- **运行时署名守卫**（`base.html:298-474`）：JS 逐字符 + 指纹重算 + 遮挡探测 + MutationObserver

### 3.2 主要模板

- **`index.html`**：文章列表卡片 + 分页，接收 `posts_page` 和 `pager`
- **`post.html`**：单篇文章（封面/标题/meta/正文/TOC/相关推荐/底部信息/评论）
- **`partials/_macros.html`**：图标 SVG 宏 `m.icon()`、JSON-LD 宏 `m.jsonld()`
- **`partials/_card.html`**：文章卡片渲染
- **`partials/_pager.html`**：分页导航
- **`partials/_comments.html`**：评论系统（giscus / utterances）

### 3.3 样式与脚本

`main.css`（1295 行）CSS 变量驱动：`:root`（`main.css:8`）定义 `--rose-50` 到 `--rose-900` 色阶 + 背景/表面/线条/文字色变量，深色模式通过 `[data-theme="dark"]` 覆盖。构建时经 `minify_css()`（`builder.py:31`）压缩。

`main.js`（505 行）IIFE 封装，负责主题切换、移动端导航、媒体灯箱、回到顶部、图片幻灯片。

## 4. v1.5.1 改进点详解

### 4.1 图片链接幻灯片

v1.5.1 用图片幻灯片替换了 v1.5.0 的音乐播放器，在左栏站点数据下方展示图片轮播。

**配置**（`config.yml:104`）：

```yaml
slideshow:
  enabled: true
  interval: 4000
  slides:
    - title: "VeryGood 主题"
      image: "https://picsum.photos/seed/verygood-1/400/225"
      url: "https://github.com/techjiang/VeryGood"
```

**模板**（`base.html:148-168`）：`.side-slideshow` 容器位于左栏站点数据注入点下方。配置通过 `window.__VG_SLIDESHOW__` 在 `<head>` 预注入（`base.html:69`）。

**JS 逻辑**（`main.js:451-503`）：

- `ssGo(i)`（`main.js:462`）：切换到指定索引，更新 slide/dot 的 `is-active` 类
- `ssNext()`（`main.js:473`）：前进到下一张
- `ssStart()`（`main.js:475`）：启动定时轮播（仅多图时）
- `ssStop()`（`main.js:480`）：停止定时器
- 交互：点击圆点切换、鼠标悬停暂停、页面不可见时暂停

**CSS**（`main.css:174-229`）：`.side-slideshow` 视口/幻灯片/圆点样式。移动端隐藏（`main.css:839`）。

### 4.2 工具栏重新布局

工具栏（主题切换/搜索/RSS）从导航底部移至头像下方。模板 `.site-tools`（`base.html:117-121`），CSS（`main.css:246-265`）。

### 4.3 左侧栏固定优化

移除 `.site-header` 的 `transition: border-color 0.3s ease`，消除滚动时边框过渡闪烁（`main.css:125-131`）：

```css
.site-header {
  position: fixed; top: 0; left: 0; right: 0; z-index: 100;
  background: color-mix(in srgb, var(--bg) 97%, transparent);
  border-bottom: 1px solid var(--line);
  /* v1.5.1：移除 transition，消除滚动时的边框闪烁 */
}
```

### 4.4 署名锁定增强

v1.5.1 将署名防护升级为四层防线：

| 层级 | 位置 | 机制 |
|------|------|------|
| CSS 层 | `main.css:791-801` | `user-select: none` + `display: block !important` + `visibility: visible !important` + `opacity: 1 !important` |
| 构建层 | `builder.py:423-567` | marker 校验 + 署名文本逐字符比对 + 双指纹（FP1/FP2）匹配 + 链接域名精确校验 |
| 运行时 | `base.html:298-474` | SHA-256 指纹重算 + 可见性/遮挡探测 + 周期性再校验（3-9s 随机间隔） |
| MutationObserver | `base.html:451-472` | 监控署名元素属性突变 + body 级结构变更 |

署名标准文本（`builder.py:21`）：`_POWER_EXPECTED = "Powered by TechSauce & VeryGood"`

构建层校验项（`builder.py:423` 起）：marker 必须在 `<footer class="site-footer">` 内、footer 全页有且仅有一个、署名行有且仅有一个、双指纹匹配、文本逐字符比对（剥离零宽/双向控制字符）、两个链接精确指向 `docs.asoe.cn` 和 `github.com/techjiang/VeryGood`（netloc 精确匹配防子串绕过）、链接文本必须恰为 `TechSauce`/`VeryGood` 且顺序不可调换、footer 内禁止 `<script>`。任何一项不通过 → `RuntimeError`，构建终止。

### 4.5 静态资源版本戳

`?v=3` → `?v=4`（`base.html:62` CSS、`base.html:475` JS），强制 GitHub Pages CDN 刷新缓存。每次修改 CSS/JS 后必须同步递增版本戳，否则用户浏览器命中旧缓存。

## 5. 如何修改主题

**改颜色**：编辑 `main.css:8` 的 `:root` CSS 变量（`--rose-50` 到 `--rose-900` 色阶 + `--bg` / `--surface` / `--line` / `--ink` 系列）。深色模式在 `[data-theme="dark"]` 下覆盖同名变量。

**改布局**：编辑 `main.css` 中 `@media` 断点（如 `main.css:832` 移动端布局）、`.site-header`（`main.css:125`）、`.layout` / `.site-main`、`.rightbar`。

**改模板**：编辑 `themes/verygood/templates/` 下的 Jinja2 模板。模板可用全局变量和函数（`builder.py:162-173`）：`cfg`（配置）、`site`（站点模型）、`url_for(path)`（站内相对 URL）、`abs_url(path)`（绝对 URL）、`tax_path(kind, name)`（标签/分类路径）、`power_fp1`/`power_fp2`（署名指纹）、`injections`（插件注入片段）、`datefmt` 过滤器。

**加功能**：通过插件系统扩展，详见 `docs/插件开发文档.md`。核心接口（`plugins/__init__.py:49` `PluginContext`）：

```python
def setup(ctx):
    ctx.register_shortcode('my_shortcode', handler)  # 短代码
    ctx.add_global('my_var', 'value')               # 全局变量
    ctx.add_filter('my_filter', filter_fn)          # Jinja 过滤器
    @ctx.hook('post_parsed')                         # 钩子
    def on_post(post): ...
    ctx.inject('sidebar_data', '<div>...</div>')     # 模板注入
```

可用钩子：`init` / `post_parsed` / `page_parsed` / `site_ready` / `tpl_context` / `finalize`。

## 6. 调试技巧

**CSS 压缩兼容性**：`minify_css()`（`builder.py:31`）用三个正则压缩——去注释（`builder.py:26` `_CSS_MIN_RE`）、压缩空白（`builder.py:27` `_WS_RE`）、规整标点间距（`builder.py:28` `_PUNC_RE`）。编辑 CSS 时不要依赖注释做逻辑分组（会被删除）。调试时可设 `build.minify: false` 跳过压缩。

**dist 与线上不一致**：`dist/` 在 `.gitignore` 中，GitHub Actions 云端重建。本地 dist 与线上的差异来源：本地含草稿、source/ 内容时差、本地未压缩 CSS。

**GitHub Pages CDN 缓存**：修改 CSS/JS 后必须递增版本戳（`base.html:62` 和 `base.html:475` 的 `?v=N`），否则用户端缓存旧版本。

**serve 模式监听范围**：监听仓库根 `plugins/` 下的 `.py` 文件（`cli.py:91`），但不监听 `verygood/plugins/` 下的内置插件。新增/删除文件可能延迟捕获（mtime 轮询间隔 1.2s）。

**署名校验失败**：修改 `base.html:267` 署名行文字会导致构建失败（`builder.py:423` 起）。限制包括：文字逐字符匹配、链接精确指向 `docs.asoe.cn` 和 `github.com/techjiang/VeryGood`、顺序不可调换、必须含 `target="_blank"` + `rel="noopener"`、marker 不可删除/移动。

**拼音 slug 调试**：`_pinyin_slug()`（`content.py:182`）依赖 `pypinyin` 库。未安装时中文标题回退为 `zhong-wen`。可通过 `python -c "from verygood.content import _pinyin_slug; print(_pinyin_slug('测试标题'))"` 验证。

## 8. 贡献指南

### 8.1 开发流程

1. Fork 仓库 → 克隆到本地 → 安装依赖
2. 创建功能分支：`git checkout -b feature/your-feature`
3. 修改代码，本地验证 `python -m verygood build` 通过
4. 提交 PR，描述改动内容与动机

### 8.2 提交前检查清单

- [ ] `python -m verygood build` 构建成功
- [ ] `python -m verygood serve` 本地预览正常
- [ ] 未修改署名行（`base.html:267`）
- [ ] CSS 编辑未破坏选择器结构（压缩后样式正确）
- [ ] 新增/修改静态资源已更新版本戳（`base.html:62` 和 `base.html:475` 的 `?v=N`）
- [ ] 新增插件已放入 `plugins/` 目录，`setup()` 正常执行
- [ ] 深浅色模式下 UI 均正常

### 8.3 禁止事项

- **不要修改署名行**：`base.html:267` 的文字、链接、顺序、属性均不可改动
- **不要删除署名守卫代码**：`base.html:298-474` 运行时守卫和 `builder.py:423-567` 构建层校验是品牌护栏
- **不要在 CSS 中用注释做逻辑分组**：`minify_css` 会删除所有 `/* */` 注释
- **不要忘记更新版本戳**：修改 CSS/JS 后必须递增 `?v=N`

### 8.4 代码风格

- Python：PEP 8 + 类型注解（`from __future__ import annotations`）
- CSS：使用 CSS 变量（`--rose-*` / `--bg-*` / `--ink-*`），不硬编码颜色
- JS：IIFE 封装，不污染全局
- 模板：Jinja2，遵循 `trim_blocks` + `lstrip_blocks`（`builder.py:156`）
